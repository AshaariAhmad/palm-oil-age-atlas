# Palm footprint and age atlas

This public, self-contained dashboard maps **regional estimates**, with interactive country, province/state, palm type, planting-year, monthly age, and area/share filters. It displays the mapped **2024** palm footprint. The 1990–2015 planting-year cohorts are estimates crosswalked from a 2021 source; the 2016–2024 codes come from TreeMap 2024. Months after December 2024 model aging of that fixed footprint. They are **not observed monthly plantation extents**.

The map outlines are 2023-vintage ADM1 boundaries. Color represents estimated palm area or share within a province/state; it is not a pixel-level plantation map. The estimates come from 50 m samples, with uncertain/unallocated area retained in country totals but omitted from the regional map.

Sources: [TreeMap 2024 v1.1](https://zenodo.org/records/20747717), [Global Oil Palm 2021 planting-year data](https://zenodo.org/records/13379129), [ESSD method paper](https://essd.copernicus.org/articles/16/5111/2024/). The separate `earth_engine_viewer.js` is the code for Earth Engine pixel-level inspection; Earth Engine execution depends on the viewer's account and access to the referenced public assets.

The [Earth Engine code snapshot](https://code.earthengine.google.com/4a803311b37603430083a77c424bcf17) was run in the Code Editor on 16 October 2026. It rendered the palm evidence layer and calculated Riau at 3,933,292.4 sampled hectares (100 m), with an area-category closure delta of 0.000 ha. The hosted dashboard uses the separately processed 50 m regional estimates, so values may differ.

Built from the local regional CSV outputs in `outputs/palm_maturity_2026/monthly_plan/regional` and generated by `build_regional_dashboard.py`. The HTML embeds all regional data and works offline.
