# Palm footprint and age atlas

This public dashboard opens on a **pixel-level overview** of the mapped **2024** oil-palm footprint, colored by planting cohort, with zoom presets for Malaysia, Sumatra, Borneo, and Java. The map is a 500 m nearest-neighbor rendering of TreeMap's 10 m raster, intended for fast web display; the separate Earth Engine viewer retains source-resolution inspection. It also provides interactive country, province/state, palm type, planting-year, monthly age, and area/share filters.

The 1990–2015 planting-year cohorts are estimates crosswalked from a 2021 source; the 2016–2024 codes come from TreeMap 2024. Months after December 2024 model aging of that fixed footprint. They are **not observed monthly plantation extents**. In regional map modes, color represents estimated palm area or share within 2023-vintage ADM1 province/state outlines. Regional estimates come from separate 50 m samples, with uncertain/unallocated area retained in country totals but omitted from the map.

Sources: [TreeMap 2024 v1.1](https://zenodo.org/records/20747717), [Global Oil Palm 2021 planting-year data](https://zenodo.org/records/13379129), [ESSD method paper](https://essd.copernicus.org/articles/16/5111/2024/). The `earth_engine_viewer.js` file is the fast source-resolution palm map, and `earth_engine_crosswalk_viewer.js` adds the 1990–2024 planting-year analysis. Earth Engine execution depends on the viewer's account and asset access.

The [fast Earth Engine code snapshot](https://code.earthengine.google.com/40577ca5b0ba5eabb5f0ef1a89e94d06) was run in the Code Editor on 16 October 2026 and displayed the source-resolution palm layer after about 10 seconds. Open the link and click **Run**; the Code Editor does not auto-execute shared snapshots. The hosted dashboard is public and does not require Earth Engine sign-in.

Built from the local regional CSV outputs in `outputs/palm_maturity_2026/monthly_plan/regional` and generated by `build_regional_dashboard.py`. The HTML embeds all regional data and works offline.
